# C++ Laboratory Projects

Welcome to **c-projects**! This repository serves as a practical space for exploring, practicing, and mastering basic-to-intermediate concepts in C and C++ through laboratory exercises and algorithmic implementations.

---

## Repository Structure

The code is organized into structured laboratory exercises:

```text
c-projects/
├── 📁 Laboratory-Exercise-1/    # C / C++ foundational programs and exercises
├── 📁 Laboratory-Exercise-2/    # Logic building and core programming problems
├── 📁 Laboratory-Exercise-3/    # Practical C/C++ applications & array/pointer operations
└── 📁 Laboratory-Exercise-4/    # Algorithms (e.g., Euclidean algorithm for GCD)
```

---

## Highlights & Algorithms Covered

- **Mathematical Algorithms:** Implementation of classic algorithms, such as the **Euclidean Algorithm** for finding the Greatest Common Divisor (GCD) of two integers.
- **Core C / C++ Concepts:** Basic syntax, logic gates, functions, control structures, array manipulation, and memory pointers.

---

## Getting Started

### Prerequisites

You need a C/C++ compiler installed on your system:
- **GCC / G++** (Linux/WSL/MinGW)
- **Clang** (macOS)
- **MSVC** (Windows Visual Studio)

### Compilation & Execution

To compile and run any exercise, navigate to its folder and build it using a compiler:

```bash
# Navigate to the specific exercise directory
cd Laboratory-Exercise-4

# Compile the source file (e.g., main.cpp or main.c)
g++ main.cpp -o app

# Execute the program
./app
```
